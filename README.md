# Problem Solving (PS) - Java Practice

Welcome to my Java problem-solving repository! This project contains a collection of standalone Java programs, utility classes, and structured challenges aimed at mastering core Java concepts, object-oriented programming (OOP), and data structures.

## 📁 Repository Structure

The project is organized into modular challenge packages, tracking my progression through various programming exercises:

* **`programming_Challenges/`** — Main directory containing numbered programming tasks.
    * **Challenges 77 - 79:** Object-Oriented Fundamentals (e.g., `BankAccount`, `Customer`, `Employee`, `TestEmployee`).
    * **Challenge 80:** Domain Modeling & Classes (`Book`, `DVD`, `LibraryItem`, `Magazine`).
    * **Challenge 81:** Core Object Methods (`equalsAndHashCode`, `Person`).
    * **Challenge 82:** Array Operations & Implementations (`ArrayOperations`, `TestArray`).
    * **Challenge 83:** Polymorphism & Inheritance (`Circles`, `Shapes`, `Square`, `TestShape`).
    * **Challenge 84:** Advanced OOP Concepts (`Bird`).
* **Core Concepts & Utilities:**
    * `89 VarArgs.java` — Working with variable arguments in Java methods.
    * `ArrayUtility.java` — Helper methods for common array manipulations.
    * `Calculator.java` — Basic arithmetic implementation.
    * `FileHandling.java` — Input/Output (I/O) streams and file management practices.

---

## 🚀 Key Concepts Covered

* **Object-Oriented Programming (OOP):** Encapsulation, Inheritance, Polymorphism, and Abstraction.
* **Java Fundamentals:** Variable Arguments (VarArgs), String Manipulation (`StringBuilder`), and Exception/File Handling.
* **Data Structures:** Array manipulation and utility algorithms.
